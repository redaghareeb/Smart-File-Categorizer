## 📌 نبذة عن المنتج

**المصنف الذكي للملفات (SFC)** هو تطبيق مكتبي ذكي يعمل على ويندوز، مصمم لحل مشكلة عالمية يعاني منها كل محترف: **الفوضى الرقمية**. آلاف الملفات المتراكمة على الأقراص الصلبة، مجلدات بلا تنظيم، ومستندات ضائعة بين عشرات المسارات.

SFC يحلل محتوى كل ملف — نصوصاً وصوراً وصوتاً وفيديو — ويصنفه تلقائياً في مجلدات منظمة حسب فئات ذكية قابلة للتخصيص. التطبيق يدعم **العربية والإنجليزية** بالكامل، مع واجهة ثنائية الاتجاه (RTL/LTR).

**مثال واقعي:** موظف لديه 50,000 ملف متراكمة على 3 أقراص → SFC يصنفها في 23+ فئة منظمة خلال ساعة واحدة، مع تقرير تفصيلي وكشف الملفات المكررة.

## 📌 Product Overview

**Smart File Categorizer (SFC)** is an intelligent Windows desktop application designed to solve a universal professional problem: **digital chaos**. Thousands of files accumulated on hard drives, folders with no organization, and documents lost across dozens of paths.

SFC analyzes the content of every file — text, images, audio, and video — and automatically categorizes them into organized folders using smart, customizable categories. The app fully supports **Arabic and English**, with a bidirectional interface (RTL/LTR).

**Real-world example:** An employee with 50,000 files scattered across 3 drives → SFC categorizes them into 23+ organized categories within an hour, with a detailed report and duplicate file detection.

### 1. 🧠 محرك تصنيف ذكي متعدد الطبقات

المحرك الأساسي للتطبيق يستخدم **تحليل كلمات مفتاحية متقدم** مع عدة طبقات ذكاء:

- **مطابقة حدود الكلمات (Word Boundary Matching):** لا يخلط بين "ears" و "ea_" — يبحث عن كلمات كاملة فقط
- **عبارات متعددة الكلمات أقوى:** "project management" (عبارة) أقوى من "project" (كلمة مفردة) بمعامل 1.5x
- **حد أدنى للتنوع:** يحتاج كلمتين مفتاحيتين مختلفتين على الأقل للتصنيف المهني — يمنع التصنيف بناءً على كلمة واحدة
- **الكلمات السلبية:** "قصة أطفال" لا تذهب أبداً لإدارة المشاريع حتى لو ذُكر فيها "مشروع"
- **أولوية التصنيفات الشخصية:** الكتب والأطفال والوثائق الشخصية دائماً لها الأولوية
- **تطبيع النص العربي:** يتعامل مع الهمزات والتشكيل وتاء المربوطة بذكاء (مثال: "إدارة" = "ادارة" = "إداره")
- **تلميحات اسم الملف والمسار:** يستفيد من اسم الملف والمجلدات الأصلية كإشارات إضافية
- **درجة التصنيف القابلة للضبط:** تحكم كامل في حد التصنيف (2.0 — 15.0)

### 1. 🧠 Multi-Layer Smart Classification Engine

The core engine uses **advanced keyword analysis** with multiple intelligence layers:

- **Word Boundary Matching:** Never confuses "ears" with "ea_" — searches for complete words only
- **Multi-word phrases score higher:** "project management" (phrase) is 1.5x stronger than "project" (single word)
- **Minimum diversity requirement:** Needs at least 2 different matching keywords for professional categories — prevents single-keyword false positives
- **Negative keywords:** A "children's story" never goes to Project Management even if "project" appears in it
- **Personal category priority:** Books, kids, and personal documents always take priority
- **Arabic text normalization:** Handles hamzas, diacritics, and taa marbuta intelligently (e.g., "إدارة" = "ادارة" = "إداره")
- **Filename & path hints:** Leverages original filename and folder structure as additional signals
- **Adjustable classification threshold:** Full control over the scoring threshold (2.0 — 15.0)

### 7. 🔁 كشف الملفات المكررة (4 طبقات)

نظام كشف متعدد الطبقات يجمع بين السرعة والدقة:

| المرحلة | الآلية | الوصف |
|---------|--------|-------|
| 1️⃣ | تطابق الحجم | فلتر فوري — حجم مختلف = ليس مكرراً |
| 2️⃣ | Hash جزئي | أول 8KB + آخر 8KB — يكشف 99% بسرعة |
| 3️⃣ | Hash كامل MD5 | تأكيد التطابق بنسبة 100% |
| 4️⃣ | بيانات وصفية | العنوان + المؤلف — يكشف نُسخ مختلفة |

**3 إجراءات عند الكشف:**
- **تقرير فقط:** CSV + JSON تفصيلي بدون حذف
- **نقل للمكررات:** نقل آمن لمجلد `_duplicates` (قابل للاسترجاع)
- **حذف نهائي:** تحرير المساحة فوراً

**اختيار النسخة الأفضل:** يحتفظ بالنسخة ذات أعلى درجة تصنيف → الأحدث تعديلاً → الأقصر مساراً.

</div>

<div dir="ltr">

### 7. 🔁 4-Layer Duplicate Detection

Multi-layered detection combining speed and accuracy: Size matching (instant filter), Partial hash (first+last 8KB — catches 99%), Full MD5 hash (100% confirmation), Metadata comparison (title + author — catches different versions).

**3 actions on detection:** Report only (CSV + JSON), Move to `_duplicates` folder (recoverable), Delete permanently (free space).

**Best copy selection:** Keeps the copy with highest classification score → most recently modified → shortest path.

</div>
